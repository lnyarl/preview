Preview 서비스의 중요한 기술 결정을 기록한다. 형식은 [MADR](https://adr.github.io/madr/) 스타일 5 섹션.

## 작성 원칙

- **결정만 기록**: 무엇을 왜 선택했는가. 토론·대화 로그는 금지.
- **대안 기록**: 탈락한 선택지와 탈락 사유를 Alternatives 섹션에 남긴다.
- **Immutable**: 한 번 Accepted된 ADR은 수정하지 않는다. 결정이 바뀌면 새 ADR로 supersede.
- **링크 허브**: 관련 코드/기획서/이전 ADR을 하이퍼링크로 연결.
